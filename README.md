# Nordly Ecommerce Store

A modern, responsive ecommerce storefront built with Next.js, React, and TypeScript.

Nordly is a portfolio project designed to demonstrate frontend ecommerce development, reusable UI architecture, responsive design, product discovery, and a complete shopping experience.

🌐 **Live Demo:** https://nordly-ecommerce-store.vercel.app/

## Overview

Nordly is a contemporary ecommerce experience featuring product browsing, collections, search, wishlist, cart, and checkout interfaces.

The project focuses on clean product presentation, intuitive navigation, responsive layouts, and maintainable component-based development.

## Features

- Responsive desktop, tablet, and mobile layouts
- Product catalog and shop pages
- Individual product pages
- Product collections
- Category browsing
- New arrivals
- Best sellers
- Product search
- Shopping cart
- Wishlist
- Checkout interface
- Order confirmation page
- Reusable React components
- Dynamic product and collection routes
- Production deployment on Vercel

## Pages

The application includes:

- `/` — Homepage
- `/shop` — Product catalog
- `/product/[slug]` — Product details
- `/collections` — Collections
- `/collections/[slug]` — Collection details
- `/category/[slug]` — Category pages
- `/new-arrivals` — New products
- `/best-sellers` — Popular products
- `/search` — Product search
- `/wishlist` — Saved products
- `/cart` — Shopping cart
- `/checkout` — Checkout
- `/order-confirmation` — Order confirmation
- `/about` — About
- `/contact` — Contact

## Local Development

Clone the repository:

```bash
git clone https://github.com/Ahmedkhayren/nordly-ecommerce-store.git
cd nordly-ecommerce-store
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

## Production Build

Create an optimized production build:

```bash
npm run build
```

The project has been tested successfully with a production Next.js build and TypeScript checks.
